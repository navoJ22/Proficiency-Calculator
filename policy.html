Privacy Policy

Last Updated: August 8, 2026

Overview

This Privacy Policy applies to the Proficiency Calculator website and Discord bot.

Information We Collect

  • Discord user ID, username, and avatar (when logged in with Discord).
  • Last selected game mode.
  • Hero mission progress, proficiency points, and hero levels.
  • Data contained within save files you choose to import.
  • Discord server information when the bot joins a server: server ID, server name, server icon, and member count.
  • Website data stored locally, including Strike Squad, last selected hero, calculator preferences, and browser save data.
  • Technical information such as browser, device information, and IP address.

Browser Storage

The website stores certain preferences and calculator data in your browser using Local Storage. This may include selected heroes, Strike Squad configuration, calculator settings, and temporary progress. This information remains on your device unless you remove it by clearing your browser's site data or using features provided by the website.

Analytics

We use Google Analytics to understand how visitors use the website. Google Analytics may collect information including pages visited, browser type, approximate location, device information, IP address, session duration, and interactions with the website.

Discord Bot

The Discord bot only processes information required to respond to slash commands and store your proficiency progress. It does not read normal Discord messages, private messages, or voice communications.

How We Use Information

  • Provide calculations.
  • Synchronize data between the website and Discord bot.
  • Support save import and export.
  • Maintain security.
  • Improve the service.

Data Deletion

You may delete your stored profile using /savefile-delete.

  • Supabase
  • Google Analytics
