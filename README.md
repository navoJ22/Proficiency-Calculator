# Proficiency Calculator

A fan-made **Marvel Rivals Proficiency Calculator** that helps you calculate XP requirements, track your progress, and plan your way to your target proficiency level.

**Website:** [navoJ Proficiency Calculator](https://navoj.proficiency-calculator.online/)

## Features

* Calculate XP requirements between proficiency levels
* Select your current and target level
* Automatically determine proficiency ranks
* Hero-specific proficiency missions
* Normal and Arcade mode support
* Save and load progress
* Import and export save files
* Local progress tracking
* Search and filter heroes
* Responsive design for desktop and mobile
* Discord integration and cross-progression
* Regularly updated with changes to the proficiency system

## Discord Bot

Website and Discord progress can also be synced by logging in with Discord, allowing information such as your current level, target level, and mission progress to be shared between both versions.

## How It Works

Select your current proficiency level and the level you want to reach.

The calculator will determine:

* Total XP required
* XP required for each level
* Available mission rewards
* Required mission progress
* Corresponding proficiency ranks

This makes it easy to see exactly how much progress is needed to reach your goal.

## Save Files

Your progress can be saved and loaded using save files.

Save files allow you to:

* Back up your progress
* Restore your progress later
* Move your progress between devices
* Transfer supported save files between compatible versions
